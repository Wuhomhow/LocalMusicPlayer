# 本地音乐播放器 Android 完整工程 (内置本地音频)

本工程是一个开箱即用的 Android 原生音乐播放器应用，内置了 3 首本地无损音频，并具备完整的现代播放器功能。

---

## 🌟 功能特性

1. **内置本地音乐**：无需联网，无需读取外部存储权限，内置 3 首轻快舒缓的音乐曲目（位于 `app/src/main/res/raw/`）。
2. **黑胶唱片旋转动效**：音乐播放时黑胶唱片持续平滑旋转，暂停时自动停驻。
3. **播放控制**：
   - 播放 / 暂停（带动态按钮切换）
   - 上一首 / 下一首
   - 进度条拖拽控制与毫秒级实时时长同步
4. **三种播放模式**：
   - 列表循环
   - 单曲循环
   - 随机播放
5. **交互式播放列表**：底部弹出式播放列表（BottomSheet），显示所有曲目并支持快速切歌。
6. **现代暗色主题 UI**：参考流媒体主流沉浸式设计，优雅护眼。

## 🚀 如何生成并导出 APK（3步搞定）

1. **解压工程**：将本压缩包解压到本地电脑任意文件夹。
2. **导入 Android Studio**：
   - 打开 **Android Studio**。
   - 选择 **Open**（或 **File -> Open...**），选中解压后的 `LocalMusicPlayer` 根目录。
   - 等待底部的 Gradle 构建同步完成（第一次打开会自动下载依赖）。
3. **一键编译 APK**：
   - 点击顶部菜单栏的 **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**。
   - 编译完成后，右下角会弹出提示框，点击 **locate** 即可在文件夹中找到编译好的 `.apk` 安装文件（通常在 `app/build/outputs/apk/debug/app-debug.apk`）。
   - 将该 APK 发送到安卓手机上安装即可运行！

## 🎵 如何替换或添加你自己的 MP3 音乐？

1. 准备你的 `.mp3` 音频文件，文件名全部改为**小写英文字母和下划线**（例如 `my_song.mp3`，注意不能有大写字母或中文）。
2. 将 MP3 文件拷贝到项目目录：`app/src/main/res/raw/` 文件夹下。
3. 打开 `MainActivity.kt`，在 `playlist` 列表中添加你的歌曲：
   ```kotlin
   Song(4, "我的自选歌曲", "歌手名", R.raw.my_song)
   ```
4. 重新点击 `Build -> Build APK(s)`，即可生成包含你专属音乐的全新安装包！
